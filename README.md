# 《萱萱飞飞大冒险》

一款温暖、梦幻的中文横版无限飞行网页游戏。玩家会陪萱萱驾驶“奶油云朵号”，穿过白天、黄昏与星夜，躲开障碍、收集星星，并用 BOOST 飞得更远。

项目是纯静态网页：无需安装程序、无需服务器、无需账号，也没有广告或内购。可直接部署到 GitHub Pages。

## 怎么玩

### 电脑

- 移动鼠标：萱萱会平滑跟随鼠标上下飞行。
- 按住空格键：开启 BOOST；松开后停止。
- `Esc`：暂停或继续游戏。

### 手机和平板

- 在游戏画面任意位置上下拖动：控制飞行高度，不必按住角色。
- 按住右下角 **BOOST**：加速；松开后停止。
- 推荐横屏游玩，竖屏也可以正常运行。

## 主要功能

- 6 种萱萱表情状态：普通、开心、兴奋、惊喜、受伤、超级开心。
- 5 种障碍与公平的安全通道生成逻辑。
- 普通星星、大星星、爱心和能量 4 种奖励。
- 3 颗生命、约 1 秒碰撞无敌、柔和震动与粒子反馈。
- 擦边不碰撞会得到 `PERFECT! +30`，连续成功可提高 Combo。
- 有限 BOOST 能量；自然恢复，也可收集能量补充。
- 白天、黄昏、梦幻星夜交叉淡化，以及三层循环视差背景。
- 分数、最高纪录、暂停、重新开始、Game Over 与 New Record 庆祝。
- 普通音效由 Web Audio API 现场生成，萱萱笑声使用 3 个真实 MP3。
- 鼠标、键盘、触摸、触控笔、刘海安全区与高清 Canvas 支持。

## 素材目录

所有游戏素材均位于 `assets/`，请保持目录和文件名不变：

```text
assets/
├── xuanxuan/    6 张角色状态 PNG
├── obstacles/   5 张障碍 PNG
├── items/       4 张奖励 PNG
├── backgrounds/ 3 张天空背景 + 3 张透明视差层
└── audio/       3 段真实笑声 MP3
```

### 替换角色 PNG

1. 准备透明背景 PNG，建议各状态使用相同画布尺寸和主体位置。
2. 用新文件覆盖 `assets/xuanxuan/` 中对应文件，但**不要修改文件名**。
3. 六个文件分别是 `normal.png`、`happy.png`、`excited.png`、`wow.png`、`hurt.png` 和 `super-happy.png`。
4. 刷新网页检查各状态是否对齐。

### 替换笑声 MP3

1. 准备音量柔和、长度较短的 MP3。
2. 覆盖 `assets/audio/baby-laugh-1.mp3`、`baby-laugh-2.mp3` 或 `baby-laugh-3.mp3`。
3. 不要更改文件名。声音只会在玩家点击“开始冒险”以后播放，并有随机概率和冷却时间。

## 开启 GitHub Pages

1. 打开 GitHub 上的项目页面。
2. 点击 **Settings（设置）** → **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择保存游戏的分支和 `/ (root)` 目录，然后点击 **Save**。
5. 等待 GitHub 显示发布地址，打开该地址即可游玩。

项目内全部资源都使用 `./assets/...` 相对路径，因此发布在 `用户名.github.io/项目名/` 这样的子目录时也能正确加载。

## 文件结构

```text
├── index.html   页面结构、菜单、HUD 与对话框
├── styles.css   全屏布局、梦幻 UI 与移动端适配
├── game.js      Canvas 游戏循环、控制、碰撞、音频与全部玩法
├── assets/      正式图片和笑声音频
└── README.md    本说明
```

## 直接运行

游戏没有构建步骤。下载整个项目后可直接打开 `index.html`；部署时也只需上传这些静态文件。部分浏览器对本地文件音频限制较严，在线部署到 GitHub Pages 后体验最完整。
